## ✨ Features

- Create, view, update and delete blog posts
- Django admin panel for managing content
- Clean, template-based pages

## ⚙️ Run Locally

```bash
# Clone the repository
git clone https://github.com/Emmanuel-3003/django-blog.git
cd django-blog/src

# Install Django
pip install django

# Set up the database and start the server
python manage.py migrate
python manage.py runserver
```

Open **http://127.0.0.1:8000** in your browser.
